# Обнаружение повторного JPEG-сжатия

Курсовая работа по дисциплине «Основы искусственных нейронных сетей», МГТУ им. Н. Э. Баумана.

**Тема:** «Исследование нейросетевых методов обнаружения повторного JPEG-сжатия изображений».

**Автор:** Гиричев М. С., ИУ7-76Б. **Руководитель:** Кудрявцев М. А.

Программа должна определять по JPEG-файлу, было ли изображение сжато один или два раза, без доступа к несжатому оригиналу. Предусмотрено самостоятельное обучение двух нейросетевых моделей и сравнение качества классификации и времени обработки.

## Сборка

```sh
./build.sh
```

Результат — `tex/report.pdf`. Служебные файлы находятся в `tex/build/`.

Основной вариант: Tectonic и совместимый с его TeX-bundle Biber. Альтернатива: TeX Live с XeLaTeX, latexmk, biblatex-gost, babel-russian и xurl. Для шрифта используется Times New Roman, при его отсутствии — TeX Gyre Termes. Для ручного выбора Biber предусмотрена переменная `BIBER_BIN`.

Настройки оформления и структура LaTeX адаптированы из [курсовой работы по компьютерной графике](https://github.com/MarkGiri/course-work-CG-BMSTU-5-sem/tree/7643a16b5e816b7f5ab96bffbae583c9d5dc1a3e/tex). Исходный Makefile использовал pdfLaTeX и Biber; сборка адаптирована для доступного Tectonic. Структура аналитического раздела также учитывает [курсовой проект по искусственному интеллекту](https://github.com/MarkGiri/course-project-AI-BMSTU-4-sem).
