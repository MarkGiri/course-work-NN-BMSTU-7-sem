# Исходный опыт с пределом в 20 эпох

В исходном опыте сравнивались MLP без dropout и CNN с 16 и 32 каналами. По валидационной кросс-энтропии выбраны MLP с инициализацией 17 (эпоха 7) и CNN с инициализацией 29 (эпоха 17). На 5 000 тестовых JPEG они дали 78,72 % и 80,44 % верных ответов. Итоговый опыт использует те же выборки DJPEG и фотографии UCID.
